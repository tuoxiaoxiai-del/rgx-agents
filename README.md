> 状态：进行中  
> 创建时间：2026-09-26

---

## 一、项目概述

将 33 本公版书蒸馏出的「书智能体」封装成可在线访问的静态网站。

- **P1 目标**：搭建静态聚合页，展示 33 门课程，支持分类筛选和试读入口
- **不包含**：支付、用户登录、后台管理（P2/P3 实现）
- **核心优势**：零 API Key，浏览器离线运行，即开即用
